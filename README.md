# 五筆字型

配方： ℞ **wubi**

这是一个基于 [Rime](https://rime.im) 引擎深度定制的五笔字型输入方案。在标准 86 版五笔之上，结合了强力的 Lua 扩展脚本，实现了极速在线造词、动态词频与多维度智能候选过滤，为您提供干净、极致的输入体验。核心特点如下：

## 核心功能

* **86 五笔基础**：基于标准 86 五笔编码，部分码位优化，支持简码、词组输入。
* **简繁切换**：可一键切换简体与香港繁体（通过 `Control + Shift + 4`）。
* **拼音反查**：输入 `/` + 拼音可反查五笔编码，辅助学习或临时输入生僻字。
* **英文混输优化**：内置英文词库（5000+常用词及绝大多数计算机、英文简写常用术语）。支持根据输入自动调整英文大小写，且在连续上屏英文单词时自动追加空格。
* **日期时间快捷输入**：支持 `rq`（日期：2026-07-28）、`sj`（时间：14:30）、`xq`（星期）、`dt`（完整时间）及 `ts`（时间戳）。
* **财务数字快捷输入**：支持 `Shift + 字母` 或 `大写字母 + 数字`，极速转换为大写会计金额（如输入 `A123.4` ➔ `壹佰贰拾叁元肆角整`），内置防越界及修正原版“0转1”逻辑错误。
* **Emoji 支持**：可输入常用 Emoji 表情，自动降频不干扰中文输入。

## 特色功能

* **沉浸式无干扰造词 (Lua 驱动)**：连续打出字词后按 `Ctrl + Enter` 触发造词。支持利用左右方向键灵活调整历史词范围，在编码输入阶段自动拦截引擎默认杂乱候选，提供纯净的界面提示。造词成功后以 `9999` 最高权重实时写入本地词库并同步内存，保证下次绝对置顶。
* **智能单页顶字上屏**：智能探测候选列表长度。当候选词仅有唯一一页时，按下 `,` 或 `.` 会直接将当前焦点词上屏，并自动补全对应的中文标点，极大提升连续输入效率。
* **长词后置与智能排序**：优先显示精准匹配的短词/单字，过长的候选词自动后置。候选词终极排序逻辑优化为：*历史记录 > 记忆词 > 英文 > 部分匹配*，并采用有限缓冲与懒加载机制，彻底消除卡顿。
* **词汇智能降频**：自动将容易误输入的纯英文单词（如 `and`、`the` 等）及 Emoji 表情降低优先级，优先保障纯中文输入的连贯性。
* **万能 Z 键与重复上屏**：支持用 `Z` 代替未知编码进行正则模糊匹配；输入 `z` 即可直接重复上一次上屏的内容。
* **简码保护与强行置顶**：通过预设配置，可将特定高频词强行固定在候选列表首位，防止被其他长词或造词覆盖。

## 操作与快捷键

* **候选选择**：可用 `;` 选第二项、`'` 选第三项。
* **翻页功能**：候选词多于一页时，使用 `,` 向前翻页，`.` 向后翻页；亦可使用 `Tab` 向下翻页，`Shift + Tab` 向上翻页。
* **以词定字（首尾提取）**：通过快捷键 `[` 仅提取当前候选词组的**第一个字**上屏；使用 `]` 仅提取**最后一个字**上屏。
* **回车行为**：在输入状态下按 `Enter` 输出原生字母/换行（结合 Shift）。
* **中英标点切换**：`Control + ;` 或 `Control + Shift + 3`。
* **简繁切换**：`Control + Shift + 4`。

## 词库与配置

* **主词库**：`wubi`
* **动态共享内存词库**：`cn_dicts/wubi.chaos.dict.yaml`（Lua 在线造词数据的实时落盘文件，具备自动压缩清理机制）。
* **自定义短语**：`custom_phrase.txt`
* **拼音反查词库**：`pinyin_simp`
* **英文词库**：`English`

## 手动加词及词频调整

* **在线极速造词**：输入需要组合的文本并上屏后，按 `Ctrl + Enter` 唤出交互界面，赋予编码后按回车，无需重启输入法即可永久生效并置顶。
* **词频批量调整**：手动调整 `phrase_weight.txt`，再使用 `replace_weight.py` 进行词频替换，可永久调整基础词库词频。
* **外部脚本加词**：提供多种编码规则，启用 `wubi.encoded.py` 脚本，按终端提示操作进行脱机加词。

## 适用场景

* 适合习惯使用 **86 五笔**、希望输入法**简洁高效且无卡顿**、同时需要**沉浸式快捷造词**、**中英混输无缝切换**、**单页智能上屏**、**金额/日期快捷输入**等硬核进阶功能的开发者或文字工作者。
* 如果需要进一步自定义，可编辑相应的 `custom_phrase.txt` 词库文件，或直接调整 `wubi.schema.yaml` 中的参数开关。
